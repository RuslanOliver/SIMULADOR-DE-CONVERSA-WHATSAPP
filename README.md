# SIMULADOR DE CONVERSA WHATSAPP

Simulador de conversa da **Ana da InfoWorld Livros Online**, com aparência inspirada no WhatsApp.

## Abrir o simulador

Abra `index.html` em um navegador. O projeto funciona como uma página estática, sem instalação de dependências.

## Funcionalidades

- Captura e uso do nome durante a conversa.
- Mensagens em sequência, com pausas para leitura.
- Aviso “Ana está digitando...” e pontos animados antes das respostas.
- Opções para conhecer o livro, tirar dúvidas sobre o valor e seguir para a compra.
- Link final para https://asprofecias2027.vercel.app/.
- Layout adaptado a celulares e computadores.

## Arquivos

| Arquivo | Uso |
| --- | --- |
| `index.html` | Simulador completo com foto de perfil incorporada. |
| `infoworld-typebot.json` | Modelo do fluxo para importar no Typebot. |

## Publicação

Para hospedar como página estática, use a raiz do repositório como pasta de publicação. Não há comando de compilação.

Este projeto simula uma conversa no navegador. A confirmação do pagamento e a entrega do livro dependem da configuração da plataforma de vendas.
